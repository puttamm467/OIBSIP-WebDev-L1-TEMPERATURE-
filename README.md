# OIBSIP-WebDev-L1-TEMPERATURE-
🌡️ Temperature Converter Website

📌 Project Overview

The Temperature Converter is a responsive and interactive web application developed using HTML5, CSS3, and JavaScript. It allows users to convert temperature values between Celsius, Fahrenheit, and Kelvin easily.

The application provides instant conversion results, validates user input, and displays user-friendly error messages for invalid temperatures.

🎯 Project Objective

To develop an interactive temperature conversion tool that performs accurate temperature conversions between Celsius, Fahrenheit, and Kelvin with proper input validation.

🛠️ Technologies Used

- HTML5 – Used to create the structure of the website.
- CSS3 – Used for styling, layouts, colors, and responsive design.
- JavaScript – Used to perform temperature calculations, handle user interactions, and validate inputs.

✨ Features

- Temperature input field for entering numeric values.
- Dropdown menu to select Celsius, Fahrenheit, or Kelvin.
- Converts temperatures into all three units simultaneously.
- Interactive Convert Temperature button.
- Displays conversion results with correct unit labels.
- Input validation to handle empty or invalid values.
- Absolute zero validation to prevent physically impossible temperatures.
- User-friendly error and success messages.
- Clean and attractive user interface.
- Responsive design for desktop and mobile devices.

🧮 Conversion Formulas

Celsius to Fahrenheit:

°F = (°C × 9/5) + 32

Fahrenheit to Celsius:

°C = (°F − 32) × 5/9

Celsius to Kelvin:

K = °C + 273.15

Kelvin to Celsius:

°C = K − 273.15

🚀 How to Run the Project

1. Download or clone this GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Open the "index.html" file.
4. Right-click and select Open with Live Server.
5. The Temperature Converter website will open in your browser.
6. Enter a temperature, select the input unit, and click the Convert button.
